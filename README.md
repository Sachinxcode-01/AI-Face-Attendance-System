# 🛡️ SmartFace AI Attendance & Security Engine

An enterprise-grade, fully automated face-recognition attendance system built with Python and Deep Learning. Powered by **InsightFace (ArcFace)** for high-accuracy GPU-accelerated facial recognition, this system completely automates classroom attendance, generates premium PDF reports, and features an active security engine to detect unregistered individuals.

---

## ✨ Key Features

* **🧠 High-Performance AI:** Utilizes the ArcFace (`buffalo_l`) model via ONNX runtime for robust, real-time face detection and recognition.
* **📊 Fully Automated Logging:** Automatically creates daily `.csv` attendance logs and master summaries, strictly marking unseen students as "Absent" at the end of the session.
* **🚨 Active Security Engine:** Detects unregistered faces in the camera frame. If an unknown person lingers, it snaps a photo and emails a professional Security Notice to the administrator.
* **🗣️ Voice Feedback System:** Greets recognized students in real-time using `pyttsx3` text-to-speech engine.
* **🎓 Premium Admin Dashboard:** A dedicated interactive CLI (`student_report.py`) to search student records, view monthly breakdowns, and export **Deep Navy & Gold Classy PDF Reports**.
* **📧 Automated PDF Delivery:** The Admin Dashboard can instantly lookup a student's email and securely send them their generated PDF attendance report.
* **📂 Auto-Sync Database:** Learns student names and roll numbers dynamically straight from the `dataset/` folder structure—no manual data entry required!

## 📂 Comprehensive Project Structure

Below is the complete architectural layout of the project and the specific role of every file and directory:

```text
SmartFace-attendance/
│
├── dataset/                    # 📁 RAW DATA: Training images organized by Name_RollNo (e.g., Sachin_25CS094). The system learns identities directly from these folder names.
├── Attendance_Logs/            # 📁 LOGS: Contains dynamically generated session logs (e.g., Attendance_2026-02-18_10-30.csv) and the continuous Master_Summary.csv.
├── Intruders/                  # 📁 SECURITY: Auto-saved high-resolution snapshots of unregistered individuals detected by the active security engine.
├── Reports/                    # 📁 EXPORTS: Auto-generated Premium PDF student reports exported by the Admin Dashboard.
│
├── attendance_system.py        # ⚙️ MAIN ENGINE: Runs the live camera feed, ArcFace AI matching, voice engine, absentee processing, and live security alerts.
├── student_report.py           # 📊 ADMIN DASHBOARD: A standalone analytics script using Pandas to aggregate logs, FPDF to generate premium PDFs, and SMTP to email students.
├── train_faces.py              # 🧠 ML SCRIPT: Extracts 512-dimensional facial embeddings from the dataset/ folder and compiles them into the memory file.
│
├── students.csv                # 🗄️ DATABASE: The core text database containing Student Names, Roll Numbers, and secure Email Addresses for report delivery.
├── face_encodings_arcface.pkl  # 💾 AI MEMORY: A serialized binary file containing the compiled facial vectors and labels generated by train_faces.py.
│
├── .env                        # 🔐 SECRETS: Stores local environment variables (like the Admin's Google App Password) safely away from source code.
├── .gitignore                  # 🚫 GIT CONFIG: Prevents sensitive files (.env, .pkl, Intruders/, Reports/) from being uploaded to GitHub.
└── README.md                   # 📖 DOCS: This documentation file.
